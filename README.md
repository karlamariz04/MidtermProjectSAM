# SysAdminPath — System Administrator Career Portfolio

A responsive React + Tailwind CSS website created for the BSIT 4D project:
**Web-Based System Administrator Career Portfolio: Certifications and Professional Development**

## Included sections

- Home / introduction and navigation
- System Administrator certifications: CompTIA A+, Network+, Security+, and Red Hat Certified System Administrator (RHCSA)
- Search and category filters for certifications
- Certification details modal with skills covered and official link
- Six skills and qualifications with explanations
- Four learning resources with working external links
- About the Developer section
- Responsive mobile navigation and layout
- Professional footer and source attribution note

## Requirements

- Node.js 18+ recommended
- npm

## Run locally

1. Extract the ZIP file.
2. Open the project folder in VS Code.
3. Open a terminal in that folder.
4. Install dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL printed in the terminal (typically `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The production-ready site is generated in `dist/`.

## Customize the About section

Edit the About the Developer section in `src/App.jsx`. Replace the name, course, introduction, and goals if you want different wording or need to add your year/section.

## Technology

- React
- Vite
- Tailwind CSS
- Lucide React icons

No database, login system, or administrator dashboard is included because the assignment does not require them.

## Certification and resource links

Certification and learning details are introductory summaries. Always verify current exam objectives, fees, requirements, and availability on the issuing organization's official website.
